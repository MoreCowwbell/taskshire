# CLAUDE.md

Everything committed to `main` is published as-is: this repository's history is the public
fork's history, and a release is a plain push of `main`.

- Plans, specs, to-do lists, changelogs and other working notes go under `notes/`, which is
  git-ignored. Never commit them, and never link to a `notes/` path from a tracked file.
- Work on `feature/` or `fix/` branches and open pull requests against `main`.
